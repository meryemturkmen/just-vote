# Just Vote

Build a mobile-first web app in English called "Just Vote". Users upload two photos of products they can't decide between (any purchase decision, e.g. shoes, a laptop, a sofa) and other people vote on which one they would rather buy. Use Supabase for database, storage and auth. Pages: Feed, Create Question, Question Detail, My Questions, Profile. Design: modern, clean, lots of white space, rounded cards, coral accent color, friendly tone. Bottom navigation with tabs: Feed, New (+), My Questions, Profile. Use the name "Just Vote" in the header and as page title.
